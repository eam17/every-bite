      Sync with GitHub

      Your lists are saved to on GitHub, and every device you connect to it shares them.

      Disconnecting keeps your lists on this device and on GitHub; it only stops syncing here and forgets the token on this device.

      Keeps your tried and want-to-try lists in a private GitHub repo, so they survive a cleared browser and follow you to other devices. No server needed. Set up takes about five minutes, once.

      1. Make a private repo. Create a new repository, name it something like every-bite-data, set it to Private, and create it. It can stay empty.
      2. Make a token for just that repo. Create a fine-grained token. Under Repository access pick Only select repositories and choose your new repo. Under Permissions, set Contents to Read and write. Pick an expiration, then generate it and copy it.
      3. Connect. Paste both below. On your other devices, open Every Bite and do this step again with the same repo and token.

      The token is saved only in this browser and only opens that one repo. Your public GitHub Pages repo never sees it, and backups don’t include it.
